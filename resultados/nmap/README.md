# Resultados do Nmap

Diretório reservado para saídas reais do Nmap. Para gerar o arquivo de reconhecimento a partir da pasta de trabalho:

```bash
nmap -sC -sV -p- 192.168.56.102 -oN resultados/nmap/reconhecimento.txt
```

O arquivo de saída não foi incluído porque os resultados originais não foram fornecidos.
